# Albatros Particle Background v2

Фоновая анимация для albatros.uz: единое поле точек (navy / blue / teal / немного red) на светлом фоне #FBFCFE.

## Хореография загрузки (~3.3 c, скорость 0.75)
1. Точки проявляются рассеянно и дрейфуют (только оттенки синего 70% и красного 30%).
2. Логотип Albatros «печатается» слева направо прямо из рассеянного поля: точки встают на места волной за полупрозрачной белой линией сканирования (спутниковые точки ×5 плотности появляются только здесь). Цвета логотипа — реальные, сэмплированные из знака.
3. Пауза ~1 c: логотип держится с лёгким дыханием.
4. Точки мягко расходятся в равномерное «созвездие» (стратифицированная сетка 8×5), контент героя проявляется каскадом; спутники исчезают мгновенно.

Клик или скролл пропускает интро сразу в состояние покоя.

## Idle / скролл
- Дрейф, линии-связи между близкими точками, параллакс и подсветка у курсора (красные линии к курсору).
- При скролле: точки сжимаются (~50%), тускнеют и текут вверх с индивидуальной параллакс-скоростью, оборачиваясь по экрану — фон живёт до конца страницы. Обратимо.

## Интеграция (Next.js)
1. `ParticleBackground3.tsx` -> `src/components/ui/ParticleBackground3.tsx`
2. `albatros-helix-mark3.png` -> `public/images/albatros-helix-mark3.png`
3. Монтировать один раз на странице, только на клиенте:

```tsx
const ParticleBackground3 = dynamic(() => import("@/components/ui/ParticleBackground3"), { ssr: false });
<ParticleBackground3 onRevealReady={(fast) => setHeroVisible(true)} />
```

Дефолты уже настроены: density 1.35, dotSize 1.05, speed 1, linkIntensity 0.55, glow 0.55.

4. Канвас fixed, z-index 0, pointer-events none. Контенту страницы: position relative, z-index 1. Убрать старый DNACanvas из HeroSection.
5. Карточки/секции — полупрозрачный белый (rgba(255,255,255,.85-.92) + backdrop-filter: blur(6px)), чтобы поле просвечивало.
6. Реакция героя: держать контент скрытым (opacity 0); по `onRevealReady(fast)` — каскад eyebrow -> строки заголовка -> подзаголовок -> кнопки, 550ms, стаггер 100ms, cubic-bezier(.2,.7,.2,1), translateY 18px -> 0; красное подчёркивание stroke-dashoffset 400 -> 0, 600ms, задержка 700ms. При fast: без стаггера, длительность ×0.4.

## Производительность
- `prefers-reduced-motion`: сразу статичное поле без интро.
- Адаптивная сложность: старт по эвристике (hardwareConcurrency <=4 или deviceMemory <=4 ГБ -> quality 0.7; <=2 -> 0.5, DPR cap 1; спутников 2 вместо 4), затем мониторинг кадров — средний кадр > 24ms на ~90 кадрах снижает quality шагами ×0.75 до 0.4 (меньше точек, при quality < 0.6 отключается glow). Понижение одностороннее.
