# Albatros Particle Background

Живой фон-«созвездие»: точки появляются, собираются в ДНК-спираль, затем в знак Albatros, и расходятся в constellation-поле. При скролле точки уменьшаются, тускнеют и параллаксно «текут» вверх до конца страницы. Обратимо, 60fps (один canvas, spatial grid для связей).

## Установка

1. Скопируйте `ParticleBackground.tsx` в `src/components/ui/`.
2. Убедитесь, что `public/images/albatros-helix-mark.png` существует (уже есть в репо — используется для фазы «знак»).
3. Подключите в лейауте или на главной ПЕРЕД остальным контентом:

```tsx
import dynamic from "next/dynamic";
const ParticleBackground = dynamic(
  () => import("@/components/ui/ParticleBackground"),
  { ssr: false }
);

// в JSX, первым элементом страницы:
<ParticleBackground />
```

4. Контент страницы должен иметь `position: relative; z-index: 1` (canvas рендерится fixed с `z-index: 0`, `pointer-events: none`).
5. Полупрозрачные поверхности (`rgba(255,255,255,.85)` + `backdrop-filter: blur`) на карточках позволяют полю просвечивать.

## Хореография загрузки (~3.2s при speed=0.75)

fade in → converge (спираль) → helix hold (вращение) → morph → mark (знак) → spread (поле) — затем reveal контента hero (staggered fade + отрисовка красного подчёркивания слева направо). Любой клик или скролл пропускает интро.

## Скролл

- `0 → 1.4·viewport`: контент hero параллаксит вниз и гаснет; точки расходятся, уменьшаются (~45%) и тускнеют (~50%).
- Поток нормализован к длине страницы: за ВЕСЬ скролл каждая точка проходит 0.6–1.8 высоты вьюпорта (оборачиваясь по вертикали) + лёгкое покачивание — на длинных страницах анимация растянута от начала до конца, поле никогда не пустеет.
- Полностью обратимо при скролле вверх.

## Пропсы (подобранные значения по умолчанию)

| prop | default | описание |
|---|---|---|
| `density` | 1.55 | множитель числа точек (базово 320) |
| `dotSize` | 1.25 | множитель радиуса точек |
| `redMix` | 0.12 | доля красных точек |
| `speed` | 0.75 | скорость хореографии |
| `linkIntensity` | 0.85 | яркость связей между точками |
| `glow` | 0.55 | ореол вокруг точек |
| `onRevealReady` | — | колбэк: пора показывать hero-контент (фаза spread) |

Hero-reveal: компонент вызывает `onRevealReady(fast: boolean)` когда точки расходятся (или интро пропущено). Подвяжите к нему framer-motion анимации hero (staggered fade, 550ms, easing `cubic-bezier(.2,.7,.2,1)`, delay 100ms между элементами; подчёркивание — `stroke-dashoffset` 400→0, 600ms, delay 700ms).

## Производительность

- DPR ограничен 1.5, связи считаются через spatial hash (ячейка 130px), сортировка по глубине только в фазах спирали.
- Сателлитные точки (×5 плотность знака) существуют только в фазах morph/mark и исчезают в первые 25% фазы spread.
- `prefers-reduced-motion`: компонент сразу переходит в статичное поле без интро.
- Адаптивная сложность для слабых устройств: стартовая эвристика (`hardwareConcurrency` ≤4 или `deviceMemory` ≤4 ГБ → quality 0.7; ≤2 → 0.5, DPR cap 1), затем мониторинг кадров — если средний кадр > 24ms на протяжении ~90 кадров, quality снижается шагами ×0.75 до 0.4: меньше точек, при quality < 0.6 отключается glow-ореол. Понижение одностороннее, без «дёргания» туда-обратно.
